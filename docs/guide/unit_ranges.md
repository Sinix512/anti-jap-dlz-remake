# 兵种普攻射程与伤害图鉴

> 每个具名兵种都可查。同名且选格/作用相同的变体合并一张卡，仍列全ID；同名但范围不同的分开。90～95为空白保留槽，不是可用兵种。

**绿色图：人物站在“我”处，可以点哪些落点。橙色图：以选中的落点为中心，哪些格会受伤。两者不是一回事！** 橙图的深框永远是落点，数字为伤害公式的倍率，不是固定伤害，也不保证最终伤害按比例（还受防御和当前HP/20保底影响）。普攻无友伤；空格照样可瞄，范围内只有敌对单位受伤。

四张橙图依次为本次预计普攻熟练1～3、4～6、7～9、10级。对应**行动前普攻次数0～43、44～133、134～298、≥299**。次数按命中的敌人数增加，不是按按钮次数；一个动作的作用范围在开始时固定，不会因中途熟练升级变大。默认朝北，改变下方朝向可查看旋转；斜瞄按主轴，斜率相等取纵向，超出地图部分裁掉。绿色选格范围不随朝向旋转。

游戏中点“攻击”后，明亮地图格表示能选的落点；鼠标停在合法落点时，**橙色格与百分比**表示本次伤害范围，浅黄框标出落点。普攻特效按同一份作用格播放；人物出招动作本身仍在原位。
