## 一、先记住这十二件事

1. **普攻没有反击**，可以多人集中火力；但敌方下一次行动仍能攻击你。
2. 普攻实际保底不是只有1伤害，还至少造成目标**当前HP的1/20（取整，下限1）**。高防不是无敌，低攻单位也能磨血。
3. **士气也是生命线**。士气越低，本体攻防越差；威慑、毒、士气雷能把单位直接打到退场。
4. 武力100封顶，**攻击没有随之封顶**：人物等级、兵种、普攻熟练、装备仍会影响攻击。
5. 升级提高最大HP，**不把当前HP补满**。普通待机也不自动回血。
6. 策略无MP、无固定使用次数；“次数”主要是熟练度。但多数敌对策略会失败，同智力成功率通常只有30%。
7. 装备放在随身包就生效，要求兵种兼容；攻、防、移各取最高，**不把两把枪的攻击相加**。
8. 仓库与背包分开。战斗只能使用人物带来的物品与雷；每人各8格。
9. 地雷**有友伤、能连爆**。一般普通雷谁踩谁触发，布雷者并不免疫。
10. 雷杀敌军不走普通缴获路径；想拿其背包装备，应先掠夺或用普攻/策略/投掷击败，再取胜结算。
11. 回合结束选择“跟随主将/各自为战”会把剩余行动交给AI，不等于安全待机。
12. 任务文字不是完整判定程序。限时、保护人物、接触事件、伏兵可能另有条件；每关先看任务与本书事件页。

## 二、操作、存档和回合

### 启动与保存

在工程目录运行：

```sh
cd .
./run_playtest.sh
```

- 战斗中：用屏幕顶部工具栏的“存档/取档”（从左侧“退出”起第3/4个按钮，悬停可看提示）。普通地图单击右键主要是取消，不是存档菜单；切到全屏地图后可双击右键打开系统菜单。
- 大地图：点右上角地雷图标，菜单里有“存档/读档”。共有**5个槽位**。
- 战斗演出、敌军行动、剧情或正在结算时不能随意保存；等恢复到我方可操作状态。
- 建议分别留“战前整备”“本关开场”“当前回合”“上一回合”“路线分支”五档，不要只覆盖唯一档。
- 本书只要求本重制版存档可用，不要求导入原版旧存档。存档记录战斗随机数状态，相同存档与相同操作通常给出相同结果；SL要换目标、走位或行动顺序，不是反复点同一招期待刷新概率。

### 一人的一轮

通常可以“移动一次，再做一个行动”，也可以原地行动。行动包括普攻、策略、用物、布雷/起雷/遥控/交雷、交物、丢物、待机。行动完成后不能再移动。

- 普通移动尚未行动时，可右键逐层退出选择，取消行动菜单会撤回原位；**踩雷中断已经消耗行动，不能当免费探雷后撤销**。
- 查看情报、查看物品不消耗行动。
- “休息/待机”只是结束此人行动，**不是治疗技能**；恢复靠策略、食物、恢复地形、携带书籍。
- 最后一个可控角色行动后可能自动进入结算，危险移动前先存档。
- 手动阶段结束后，其余单位按人物槽顺序行动，并非严格“全部友军完，再全部敌军”。己方自动单位也可能插在队列里。
- “原地待命”最可控；“跟随主将/各自为战”只对尚未行动的人接管AI。

### 移动与卡位

地图按四方向寻路，不是八方向移动。移动力是**预算**，每步支付进入格的地形代价；不可通行格不能进入。

同阵营可以穿过但不能重叠停留，敌军格不可穿过。进入异阵营单位的上下左右邻格后，剩余移动扩散停止（ZOC）；起点本就在敌军旁边时仍可离开。斜邻不产生这一ZOC。

**推导：**堵路要考虑四邻、同阵营穿人和敌人射程，不要把“有一人挡前面”当所有后排都安全。射程按模板判断，没有额外通用的树林/房屋视线遮挡判定；炮与枪也可能有近身盲区。

## 三、人物成长与练级

### 四种成长不是一回事

|内容|提升方式|上限/注意|
|---|---|---|
|人物等级|获得经验，每100经验升1级|99；升级不补当前血|
|武力/智力|开局分配、属性书、少数剧情改动|各100；不是每级自动各加1|
|普攻熟练|普攻有效命中目标累计|最高10级；群攻一次命中多个人会累计多次|
|策略熟练|该策略影响有效目标累计|最高10级；未奏效不涨，满血补给等无实际恢复不涨|

熟练1～10级对应累计次数：**1、10、25、45、70、100、135、175、225、300**。0次为0级，一般有技能者从1次起。

普攻熟练提高本体攻击系数；部分兵种的群攻范围也随熟练变化。策略熟练提高数值、部分作用范围；不普遍提高成功率，掠夺是额外加熟练等级的例外。

**没有“过一关全队白送经验”**。不要把参战但没输出/没有效辅助理解为必定成长。雷杀有全体分配，详见后文。

### 经验怎么算

下表为我方普攻命中/普通击杀基础经验，等级差=目标等级−自己等级：

|等级差|命中经验|击杀经验|
|---|---:|---:|
|≤−7|1|1|
|−6～−4|2|2|
|−3～−2|4|4|
|−1|6|8|
|0|8|12|
|+1|16|16|
|+2|24|32|
|+3|32|48|
|+4|32|64|
|≥+5|32|80|

- 普攻：有效目标命中经验相加，**命中部分每次行动最多48**，再加各击杀经验。
- 敌方普攻命中经验按上述右移2位计算，不要拿我方成长速度直接推敌人。
- 策略：有效辅助/伤害/减益有行动经验，**基础部分最多16，再加击杀经验**。补给/激励按实际恢复占本次基础效果比例计算；治疗满额不等于固定12经验，因为作用格倍率也会影响实际恢复。
- 火攻/滚木/擂石、威慑按实际造成的HP/士气变化与基础效果比例算；其他策略通常每有效目标8基础经验。满状态空刷恢复不算有效。
- 投掷物：没有普通命中经验，击杀给**该目标击杀经验的一半（取整）**。
- 地雷击败非我方单位：先算 `R=max(4,(死者等级−本关index)*8+12)`；`N=当前存活我方slot0..39人数`，若N>0，奖励 `min(12,max(1,R/N)+8)`，发给存活我方slot0..59。一般正常队伍每人得9～12；不是给埋雷者独吞。群体连续退场逐人计算，分母可变。

### 开局与分工

自建主角可选手枪、大刀、步枪、骑兵四系；武力60～100，智力=160−武力。自建主角额外拥有补给、激励，并继承所选兵种的技能；不应照搬某个默认姓名的技能表。

**推导：**

- 高武主角适合稳定输出，但初期智力低，敌对策略不可靠。先靠补给、激励稳定积累，不拿疑兵当必成功保命。
- 高智角色负责治疗、控制、掠夺；武力书优先给仍有提升空间且承担普攻者。
- 给主力集中击杀能快速拉等级；低级队友至少参与安全命中、有效辅助或雷杀分经验，别一直只搬运。
- 学新兵种技能时，旧的非零策略熟练保留。常规转职只给新兵种有、自己不会的策略补到1，不会自动把所有新技能练满。剧情可另行重写技能。

## 四、攻防伤害：面板应该怎么看

所有公式按执行次序**逐步整数截断**；不要最后才统一取整。设武力W、智力I、等级L、攻击熟练等级S、士气M（0～100），完整度初始100。

```text
基础体力上限 = 兵种基础HP + (L−1)×HP成长
R = 基础攻击×3×W/100 + (攻击成长−1)×(L−1)
A = (S+59) × (R×(W+500)/580) /60
A = A×攻击完整度/100
A = A×(M+100)/200
最终攻击 = max(1,A+兼容装备最大攻击加成)

D = 基础防御 + (L−1)×防御成长
D = D×防御完整度/100
D = D×(M+100)/200
D = D×(100+所站地形防御修正)/100
最终防御 = max(0,D+兼容装备最大防御加成)

普攻理论伤害 = max(1,(最终攻击−最终防御)×作用格倍率/100)
普攻实际伤害 = min(目标当前HP,max(1,目标当前HP/20,普攻理论伤害))
策略基础效果E(P) = ((P×I/100)×(策略熟练等级+7))/8
```

- 兵种表“基础攻击40”**不代表最终攻击40**，武力在公式里不止用一次；比较兵种请看附录同条件示例列。
- 地形防御是本体乘法修正，不是最终防御直接加几点，也不再次放大装备防御。
- 骚扰/破坏缩放本体完整度，装备额外值不随之一起乘0.7。
- 士气100时本体系数100%；士气50时75%；士气0时50%。装备加成在其后。低士气已可能被技能/雷直接判退场，别拿0士气硬抗。
- 普攻HP伤害还会扣士气：`max(1,20×实际HP伤害/最大HP)`。技能、雷、投掷不统一套这个额外扣士气规则，各按自身通道。
- 残血不会自动按HP比例削弱本体攻防；要看士气、完整度等实际状态。普攻合法命中没有一般敌对策略那种智力成功率roll。
- 普攻、伤害策略、投掷和雷都没有通用的“装甲减伤百分比”；**策略/投掷/雷不走普攻防御差**。重甲高防敌人可考虑这些手段。

### 一个明确的例子

1级大刀队、武力100、普攻熟练1、士气100、无装备：本体攻击124，防御40；1级武力80同条件本体攻击96。站地形T10（防御+30%）时防御52，不是70。若带防御+6装备，最终58。

若攻击124打防御100、当前HP400的目标：100%作用格伤害24；若其防御200，仍有当前HP的1/20，即20伤害。此保底随剩余HP下降，不能简单认为“固定20下击败”。

## 五、兵种选择与晋升

完整基础值、成长、地形移动、技能和适配装备见全数值表。**同名不同ID可能不同属性/阵营模板**，如手枪队1/23/48，不可混为一条。

|我方常规路线|定位与实际取舍（规则推导）|
|---|---|
|手枪→双枪→冲锋|控制辅助丰富；双枪基础攻击80，冲锋反而60，换来移动/范围变化，晋升不是所有数值单调上升|
|大刀→武术|近身输出、滚木、破坏；大刀选目标为四邻，不是周围八格；练范围后注意方向与波及格|
|民兵→野战|HP成长18突出；民兵只能攻击正交恰好2格，野战环状射程，别当贴身肉搏兵|
|步枪→机枪→重机枪|远射与群攻，但模板存在近身盲区；需要前排、ZOC和距离管理，不是无代价高射程|
|骑兵→轻骑→骠骑|选目标由直线1格到直线2/3格，群攻模板变化；基础移动都是4，**名字叫骑兵不代表裸装移动必然更高**，马匹装备和地形代价才关键|
|土炮→大炮→重炮|基础移动3；长射程但有盲区，作用范围会随普攻熟练变化；先计划推进路线与保护|
|武工→飞虎|较高基础防御50，多种控制/减益；适合协助拆高防目标，不代表策略必命中|
|儿童团→童子军|移动5、掠夺/火攻/疑兵，适合拿物与辅助；基础攻防低，避免拿去硬接集火|
|妇救会→娘子军|医疗与威慑/疑兵；娘子军再有补给，优先保证能安全施法|

### 晋升与横向转职

- 普通晋升要求相应道具与兵种兼容，一般**15级**；第二段用75～78号经典书要求**30级**。儿童团/妇救会的常规晋升也是15级。
- 其他兼容兵书按物品目标兵种横转，不一概要求15/30级；允许范围见每件兵书适配表。
- 等级、经验、武智不因普通转职清零；最大HP按新兵种和当前等级重算，不赠送满血。普通晋升路径当前HP保留；横转会向下夹到新上限。
- 转职后装备可能不再兼容，行动前重新检查攻击、防御、移动。
- **战斗中使用兵书，即使取消确认、不兼容或等级不够，也会花掉本次行动；只有成功才消耗书。**
- 兵种0神仙队及大量剧情/敌军模板不是普通开局可选项。附录保留它们用于识敌，不暗示能在商店无限招募。

## 六、全部策略的实际作用

先看附录的射程示意，选目标范围与作用范围不是同一个概念。可以点空地让群体效果波及周围单位；“影响0目标”既可能是概率失败，也可能落点/阵营/作用范围不符。

|策略|实际效果|核心限制/用途|
|---|---|---|
|补给|恢复HP，基础参数120|无成功率判定；可给自己；满血无有效成长|
|激励|恢复士气，参数20|无成功率判定；可给自己；士气影响攻防|
|医疗|恢复HP120、士气10|无成功率判定；可给自己；同时照顾两条状态|
|火攻|HP伤害80|敌对概率；乘目标地形“火攻”修正，不减防御|
|滚木|HP伤害80|敌对概率；乘目标地形“滚木/擂石”修正|
|擂石|HP伤害80|与滚木读同一地形列；不是另一个岩石专属倍率|
|威慑|士气伤害20|敌对概率；士气降至0可退场|
|骚扰|防御完整度×0.7，最低20|敌对概率；连续有效施放可叠；不等于最终防御直接减30%|
|破坏|攻击完整度×0.7，最低50|敌对概率；连续有效施放可叠；不削掉装备加成|
|掠夺|偷对方普通物品包第一个非空槽的一件|敌对概率+熟练等级；不是偷钱或偷雷；自己满包则记临时缴获，须获胜结算|
|反间|目标等级−1，最低1；重算HP上限|敌对概率；**不是招降/变阵营**|
|疑兵|标记敌人已移动、已行动|敌对概率；跳过当前即将进行的行动，不是固定晕几回合|
|督战|友方恢复移动/行动资格；攻防完整度各补20至100|也要成功率判定；兵种45督战队不能被此技能重置；施术者最终仍已行动|
|暗杀|HP基础参数10000|敌对概率，不是无条件斩杀，也不按目标剩余HP百分比|
|施毒|HP180、士气40|敌对概率；直接结算两条，不是后续持续毒伤|
|空袭|HP400|无成功率判定；选目标模板15形状特殊，必须看图，不是全图打击|

带参数的效果先算上一节E(P)，再乘作用格倍率；火攻/滚木/擂石再乘目标所站地形修正。控制、降级、减益等固定效果不因作用格50%就自动变成“半次”。

除补给、激励、医疗、空袭外，逐目标成功率：

```text
成功率 = 限制在0%～100%的 [30+2×(我智力−敌智力)]
掠夺另加自身策略熟练等级（0～10）个百分点
```

智力差−15/0/+10/+20/+35时，普通成功率为0/30/50/70/100%。群体技能对每个目标分别判断，不是一人成功全体成功；全部失败也消耗施术者这次行动。

**四人初期角色举例：**选骑兵的主角通常用补给/激励稳队伍，威慑/疑兵伺机；朱老忠滚木/破坏；赵虎火攻/骚扰；张嘎火攻/掠夺/疑兵。主角选别的兵种会不同，剧情、转职也能改技能，人物当前情报优先。

**组合推导：**先骚扰再由多人普攻；先破坏降低高威胁者输出；控制只安排为有失败预案的加成，不把低概率疑兵当唯一护送保险。督战相当于花施术者行动换队友再动，应优先给强输出/救急治疗，而非无收益搬运。

## 七、16种地形与阵地

附录完整列出16×5修正和96×16移动代价。原数据没有已核实的中文地形名表，本书用**T0～T15**精确对应，**不猜“树林/平原/山地”标签**；离线版逐关地形图可把屏幕地块对到坐标与T号。

五列的真实意义依次是：火攻HP修正%、滚木/擂石HP修正%、本体防御修正%、每新轮恢复最大HP比例%、每新轮回复士气点。

- T0火攻+40%、滚木/擂石−20%、防御+10%；“站着防御高一点”不等于防火。
- T3滚木/擂石+40%、防御+10%，对相应策略更脆。
- T9/T10/T11/T12是恢复地形，分别每新轮回最大HP的20/30/10/20%，士气+10/15/5/10。
- T10防御+30%，T11防御+40%；两者恢复强弱不同。
- 恢复地形对**敌我双方**都生效；31/32号恢复书额外部分只给我方。
- 新轮先执行回合事件，再地形/书恢复，再处理定时雷，最后查相关事件；开场第1轮不额外白回一次。

**推导：**防御战可争恢复格；进攻时不要让敌人稳定占格拖满血。火攻打T0/T12收益较好，滚木/擂石打T3较好。雷不吃地形伤害倍率；能否埋设是另一张独立表。

## 八、装备、消耗品与背包

### 携带即装备

每人八个普通物品槽，八个雷槽。兼容装备带在包里即生效，无需点“使用”。攻击、防御、移动分别取最大：例如A加攻击20防御5、B加攻击10防御12，合计是攻击20防御12，不是攻击30防御17。

- 新买不会自动替换旧件；旧物仍占格。
- 不兼容也能带着，但不提供加成。坐骑也要适配，别看到“移动+3”就给所有人买。
- 武器不会把兵种的射程/群攻模板换成武器名称描述；射程主要看兵种。
- 31/32号被动恢复书按**每本**处理，可叠，不按装备最大值规则；回复封到上限，不消耗书。
- 31《论持久战》每新轮回最大HP25%、士气10；32《少林真经》每新轮回最大HP15%。高价长线投资，前提是当前关能活到下一轮。
- 33～40属性书只作用自己，武智封顶100；封顶仍吃掉物品与行动，不要浪费纯武力书给武力100者。

### 食物与投掷物

- 食物实际回复看附录HP/士气与范围，有些能群体补给；不是所有粮食都只给一个人。
- **酒类21～30当前实现用了也不恢复任何状态，但会消耗物品和行动。**这是现存行为，不是推荐机制。
- 投掷物直接扣HP/士气，不受武力、智力或普攻防御差影响；按作用格倍率缩放。只有击杀给半份经验，练级效率与普攻不同。
- 投掷/食物选择界面可能允许点空格、敌我位置，但效果按阵营过滤；能点不代表一定有效。
- 全部有效物品、占位槽、不生效/特殊物品均在附录分开标注，不把160个槽说成160件可购买商品。

### 交物、宝箱、缴获

城镇转交会检查接收者空间；战斗交物/交雷当前则可能**先从源包移除，目标满包就丢失**。起雷满包也可能丢失。操作前腾格；战斗转交不一定有阵营保护，确认人物。

宝箱是**谁结束行动站上去谁开**，敌人也能开：

- 开箱者有空位→物品归其背包，并可能立刻影响其装备属性。
- 开箱者满包→当前逻辑送入我方正式仓库（敌人也一样）。
- 敌人拿走后，普攻/策略/投掷击败它，会把剩余普通物品记入临时缴获；**战斗胜利并确认战报才结入仓库**。失败/重来不结。
- 若用雷击败，**不调用该普通缴获流程**；不是一定以后能拿回来。可先掠夺，或把最后一击留给非雷伤害。
- 主动移动尚未提交行动时，宝箱不会提前变成可无限撤销的免费领取。

## 九、地雷：伤害、布置与引信

十个基本雷种×四个引信，共40种成品。主威力、爆区、配方、材料成本、解锁点、可埋地形见附录。

|引信|触发方式|额外制作钱|
|---|---|---:|
|普通|单位踩入触发；我方也触发|0|
|引爆|不能靠踩入直接触发；可被别的雷爆区连锁带爆|0|
|定时|设置1～10轮，新轮维护倒计时到期即炸|80|
|遥控|角色在曼哈顿距离1～5内用遥控命令引爆；可连爆|300|

四类引信不额外乘伤害。普通雷踩中会中断这次移动并消耗行动。兵种46工兵队踩上时会移除该雷而不爆，不把这个能力泛化给所有叫工兵的人或所有兵种。

### 爆炸怎么算

每个作用格伤害为 `雷威力×格子倍率/100`，扣HP或士气取决于雷种；不看普攻攻防、武智、士气增伤，也不按地形增减。**不分阵营。**

一颗雷的作用格覆盖其他雷时，会把它们排入连爆队列；引信、所有者都不能阻止被连锁。HP雷不顺带扣普攻那份士气；士气雷可直接令0士气单位退场。没有另加持续中毒/燃烧回合。

### 五项雷操作

- 埋设：周围八邻空格，需人物带着雷、无人物/无现存雷、地形许可；第15/18关（index14/17）禁手工埋设。
- 起出：周围八邻的现有可操作雷，起后进自己的雷包；满包会丢。
- 定时：给已有计时雷重设1～10轮，也耗行动；不是所有地图雷都能改定时。
- 遥控：距离1～5，目标必须遥控类；自己脚下不属于可选范围。
- 交雷：周围八邻角色；满包风险同上。

**定时例：**设1轮写倒计时2；结束本轮、AI行动后进入下一轮维护，此时爆炸。设2轮则下一轮先减为2，再下一轮爆。别把“1轮”理解为自己还能整轮站着准备撤离。

**实现怪点：**可埋地形实际按成品编码 `code/4` 的整数行索引，不是按雷种 `code%10`。因此同一雷种换引信，许可地形可能不同。附录列40种实际许可，避免凭外观猜。

**推导：**先算敌人何时走到、自己的撤退路径、爆区与连锁，再埋。把雷布在本方下一轮必经格会反噬；狭窄地形也可能被敌人停在ZOC边缘而不踩到。雷清场换稳定性但可能牺牲装备缴获、主力独享击杀经验，按本关需求取舍。

## 十、军械部、杂货铺、作坊与资金

军械部和杂货铺共享资金/仓库，不是各有一份库存。

|界面/动作|结果|
|---|---|
|买入/物品模式，拖商品给人物|付钱，直进此人随身包|
|买入/物品模式，拖商品到库房|付钱，进公共仓库|
|交换，点人物后拖其物品给别人|不买卖，人物间转交|
|交换，拖到库房|退回仓库|
|分配，拖仓库物给人物|领用，不再付钱|
|拖到“上交”|出售，不是免费寄存|

普通难度卖价为标价60%，简单70%，困难50%，材料也如此并整数取整。补货后反悔转卖会亏钱。

军械部/杂货铺每镇普通商品最多12件（6×2），材料10个入口（5×2）；仓库可翻页，下方箭头滚动人物。各镇售货目录不同，不是全商品都有；旧材料目录多两份粘土入口已修，不是新资源奖励。

作坊按配方消耗十类材料，再收定时80/遥控300的额外钱；雷种与引信都要先解锁。**基本雷种的“回收价”不是制造费**，制造实际成本看材料和引信。

- 仓库回收雷：按基本雷种价格。
- 人物身上回收雷：当前实现按引信号取雷价格，数值可能和仓库不同；这是保留的怪行为，先退仓再回收更好核对。
- 民房名称虽有旧函数叫“heal”，当前正式流程主要是剧情、配方/引信解锁与彩蛋，**不是点一下就免费治全队**。
- 正常人物重新部署时按当前兵种/等级以满HP生成；开场脚本随后可能改HP或阵营，NPC和特殊关模板不一概满状态。战斗内升级/转职不自动满血。
- 主线没有统一“每关奖励800”或统一过关经验；钱来自具体剧情奖励、交易等。不要把早期原型meta字段当当前奖励。

**推导：**优先确保主力有一件实际提升的兼容武器、必需的移动装备、关键恢复品/兵书，再投入昂贵雷与书；对只在后方辅助者重复买高攻击装备往往收益低。记账时分清仓库货、随身货与尚未胜利结算的临时缴获。

## 十一、难度、伤亡、评分与隐藏路线

### 难度不等于敌人统一乘血

正式部署按我方slot0～31已出场者平均等级算：`G=平均等级−(本关index×2+1)`。主线index<36、非简单、G≥2时，非我方初始在场角色等级上调：普通 `G/2`，困难 `G×4/5`，最高99。之后按其兵种和等级重算满HP。

所以“带一个高等级主将和大量低级队友”与“精简高等级队伍”会影响平均值；不是刷等级永远只利于己方。代码里旧的0.75/1.15难度缩放helper不代表正式战役把所有敌人HP统一乘它。

### 伤亡还有主将扣级

普通/困难下，我方可部署队员阵亡可能使主角掉1级（不低于1），重算最大HP；简单不罚。普通多数普攻/策略/雷死亡路径按**累计损失递增后<3**判断，前两次损失会罚；投掷路径在递增前判断，第三次也可能罚。困难每次符合条件的损失都罚。NPC/保护目标还可能直接判败，不能拿“牺牲队友过关”当无代价方案。

### 单关评分

```text
原始值=max(0,10×非雷击杀数+10×雷击杀数+50−40×损失数−回合数)
分数=原始值×100/本关难度分母+难度档×2
难度档：简单0、普通1、困难2
```

“非雷击杀”统计名叫gun，也包含部分策略/投掷路径，不只枪械。回合快、零损失有利评分；不必为凑击杀冒险让保护人物死。评分可超过100，旧资料中的score_max不是硬封顶。

主线结束冻结总分S：2800解锁隐藏路线首关，3000/3300/3600分别允许推进到第2/3/4关。模拟36～39与虚构40～43是分支，不是单档自然串成连续八关。彩蛋44～46另由桃花岭民房的30%访问分支、相关未触发标志等决定，不是随便点一个隐藏关菜单就算自然路线。

本书用人类关号1～47并附index0～46。隐藏与彩蛋条目“第37关”等仅是资料序号，**不表示普通主线一定会到那里**。

## 十二、可以直接用的战术检查单（推导，不是保胜脚本）

### 每关开场

1. 看胜利、失败、时限和保护人物；先确定是赶路、全歼还是关键事件，别只追敌人。
2. 检查NPC可控/自动、谁被排除部署、增援何时从哪出；保护对象是否先天残血。
3. 查看敌方HP、士气、智力、防御、攻击射程、背包装备；地形恢复格双方都能利用。
4. 存开场档；分配主攻、治疗、控场、搬雷/拿箱任务。不把同一个人同时安排“这轮补给”和“这轮疑兵”。

### 每轮行动顺序

1. 先处理主角/保护人物能否活过下一次敌方行动。
2. 高防目标先尝试骚扰，低智高威胁目标可疑兵/破坏；失败后换可实现的退路。
3. 多人集火减少敌方下一轮有效攻击数。无反击让补刀成本低，但仍要计算敌方移动后射程。
4. 把高价值击杀留给需要成长者，辅助给真正缺血/士气的人；不要为了经验多挨一轮集火。
5. 布雷者结束行动前核对友军撤离，遥控先清空己方爆区。需要缴获的敌人留非雷最后一击。
6. 优先让尚有任务的人行动；最后一人行动可能自动结束本轮。无意接管时选“原地待命”。

### 常见卡关诊断

- 打不动：查士气、装备兼容、攻防完整度；用骚扰/固定伤害/绕开恢复地形，不先认定数值无解。
- 明明在附近打不到：查射程盲区及模板，距离数字不足以判断；步枪/炮尤其如此。
- 技能没用：查智力差、阵营、作用格、状态已满；不是每个技能都必中。
- 总被围：查ZOC和敌人移动预算，别只看当前位置；用有余地的阵线，而不是挤在同一爆区。
- 一直不成长：看是否只有待机/搬运/无效辅助，是否用投掷而非普攻，是否全部击杀集中一人。
- 超时：查看事件页；某些任务不会因“接近救援对象/打死头目”立即胜，别从任务名自行猜判定。

## 十三、现存异常与不应误导玩家的地方

1. **自己踩雷后仍有软锁反馈，尚未彻底解决。**此前只修了一个选择/菜单残留路径；不保证右键必能恢复。发生时不要覆盖唯一存档，保留关卡/回合/人物/雷种、操作前后存档与日志给定位会话。
2. 酒21～30耗行动/物品但不回血或回士气。
3. 战斗交物/交雷/起雷满包可丢失。
4. 用兵书取消/失败仍耗行动。
5. 雷杀不收普通背包缴获；敌军也开箱；装备三项不叠加。
6. 地雷许可索引与人物雷回收价存在怪点，已按现代码列出，不为“原汁原味”辩护，也不在本轮擅改。
7. 47关规则、模板与触发器覆盖不等于47关自然通关验证；数值表完整不等于长流程没有bug。

## 十四、实测边界与维护

已有用户战报证实：第8关「攻占土桥」30回合胜、21杀、零损失；第9关「救援白洋淀」18回合胜、16杀（7雷杀）、零损失。只能据此确认这些战果，**没有完整操作录像，不能倒推出逐回合保胜走法**。历史自动玩家并未达到相同战绩，失败不证明游戏必然无解。

本书静态资料按当前模板与脚本生成。敌人会因难度、成长与剧情变化；人物表是初始模板，不是你的存档现值。坐标以左上角(0,0)计，x向右、y向下。触发器按实际顺序检查，有些事件会继续执行或改写胜败，不能把每条孤立理解为无条件立即发生。

```sh
cd .

python3 tools/build_player_guide.py --check

```
