# 触控操作

Android 自动启用触控模式，保持横屏、640×480 等比显示。桌面默认只使用原鼠标和快捷键，不因检测到触摸屏或收到触摸事件自动切换；仅显式追加 `-- --touch-ui` 时启用触控调试界面。

## 战斗

- 点人物选中后，点可达格立即移动，不需要第二次确认；点人物原格立即进入行动菜单。正常移动仍是原可撤回的暂移，在结束行动前可取消回到移动前的位置；踩雷等原规则后果不因触控改变。
- 会结束人物行动的普攻、策略、物品及地雷最终目标先预览，再点同格或顶部“确认”提交。定时地雷的目标格只打开回合选择，不要求额外确认；选定回合即确认并结束行动。休息、丢弃物品及尝试使用转职/升级手册有明确的结束行动确认；取消这层确认不消耗行动或物品。确认尝试手册后进入原升级/转职流程，其内部选择“否”或条件不满足仍按原规则结束行动，仅成功时消耗手册。策略显示可生效/不可生效格和逐格概率；普攻百分比是范围伤害倍率，不是命中概率。
- 单指拖动地图平移，不会把抬手当成移动或攻击。双指、取消触摸、切到后台会取消当前手势，必须重新点格确认。
- 长按人物查看情报，不消耗行动；查看其他人物也保留当前人物暂移后的撤回能力。
- 攻击、策略等选格及预览阶段，顶部明确显示可点击的“取消攻击”“取消策略”等按钮，返回行动菜单、不消耗行动；再取消行动菜单可撤回暂移。桌面同样有普通 HUD 取消按钮，但不启用触控确认、提示条或触控菜单。顶部“取消”逐层返回，“菜单”可打开存档、取档、速度、结束回合、任务与分屏等操作。长菜单分列，不需键盘或悬停。
- Android 系统返回键/返回手势等同于取消当前顶层操作，不直接退出游戏。退出仍通过原确认流程。

## 剧情、经营与部署

- 剧情可点画面或“继续”；先显示完整文字，再继续。情报、通知与选择窗有明确返回/取消按钮。
- 商店点商品，再点人物或库房；长按看详情，不交易。库房出售保留连续出售能力，可调整数量并确认，每次只结算一笔。
- 数量窗支持点数字输入、±、最大、购买与取消，不会一打开就弹软键盘。翻页仍可点箭头，背包列表可滑动。
- 部署点人物在两侧转移，长按看详情，点“确定”出战；强制出场人物仍不能移除。
- 地雷分配可点源，再点人物、库房或卖出目标，不要求鼠标拖放。

## 验证与边界

`python3 tools/verify_touch.py` 运行真实 ScreenTouch/ScreenDrag 夹具及桌面定向回归；每项使用独立日志。`--suite touch` 或 `--suite desktop` 可分别运行。

APK 的生成、签名、安装与设备要求见 [Android 打包说明](android.md)。本次验收不等于全 47 关通关、所有真机兼容、长期后台恢复或历史踩雷软锁闭合证明；不会为适配修改数值、AI 或存档格式。
